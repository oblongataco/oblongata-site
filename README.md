# oblongata.co

The Oblongata website.

## Files
- `index.html` — the site
- `tweaks-panel.jsx` — design tweaks panel (visible only when toggled)
- `assets/` — team portraits

## Deploying
Auto-deploys to Netlify on every push to `main`. No build step — Netlify just serves `index.html` directly.

## Contact form
Submissions are routed through [Formspree](https://formspree.io) (`mqenperw`) and forwarded to joe@oblongata.co.

## Updating
Edit files locally → commit → push. Netlify rebuilds within ~30 seconds.
